# Journal de bord

Ce dossier rassemble les comptes rendus du homelab : installations, incidents, tests de restauration, vérifications des règles de firewall. Un fichier par entrée, nommé `AAAA-MM-JJ-sujet.md`.

## Modèle

```markdown
# AAAA-MM-JJ — Titre court

## Contexte
Ce que je voulais faire, et sur quel équipement.

## Ce qui s'est passé
Commandes lancées, messages d'erreur, comportement observé.

## Diagnostic
Les pistes testées, celles qui ont été écartées et pourquoi.

## Solution
Ce qui a fonctionné, avec les commandes ou la configuration finale.

## À retenir
Une ou deux leçons, et ce qu'il faut mettre à jour dans la documentation.
```
